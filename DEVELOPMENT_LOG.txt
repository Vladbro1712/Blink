BLINK DEVELOPMENT LOG
======================

Project
-------
Blink is a customizable music player planned for Windows, Android, iPhone, and the Web. Its initial design follows the warm neutral palette supplied with the brief.

Completed
---------
- Created a React, TypeScript, and Vite application in C:\Code\Blink.
- Added Russian-language home, favorites, and settings screens with responsive desktop and mobile layouts.
- Added the initial Spotify, VK Music, and Yandex Music platform picker and connection status labels.
- Added saved platform selection and the remember-selection setting.
- Added track search, favorite toggles, player controls, track navigation, and volume control, using clearly labeled sample/demo tracks.
- Added palette customization controls and an alternate neutral theme.
- Created six local generated raster cover images so the app does not rely on image hosting.
- Added Electron desktop app configuration and built the Windows NSIS installer.
- Added Capacitor dependencies and configuration for a future Android shell.
- Created the user guide and development log.
- Added local audio file import, a persistent IndexedDB library, a dedicated All Tracks screen, and favorites keyed by file.
- Connected play/pause, track navigation, seeking, duration display, volume, and end-of-track navigation to actual local audio playback.
- Fixed malformed JSX in the working tree that was preventing the app from compiling.
- Fixed the blank Electron window by configuring Vite to emit relative asset URLs for file:// packaged builds.
- Kept the remember-selection checkbox in the platform picker; removed duplicate remember-selection and theme controls from Settings as requested.
- Removed the unused alternate theme control and palette swatches from Settings.
- Fixed cover asset URLs so images load in packaged Electron builds using file://.
- Added Spotify Authorization Code with PKCE for the closed beta. The public Client ID is used by the renderer; no Client Secret is stored or requested.
- Added an Electron-only loopback callback at http://127.0.0.1:43821/callback, state validation, encrypted token storage through Windows safeStorage, token refresh, and disconnect handling.
- Added an initial Spotify Web Playback SDK integration: Blink loads the official SDK, exposes a refreshed PKCE access token to it through the protected Electron bridge, registers a `Blink` Spotify Connect device, transfers playback to that device, and controls play/pause, seek, and volume. Local audio playback remains on the native HTML audio element.
- Spotify Web Playback SDK requires a Spotify Premium account and a fresh authorization after adding `streaming` and `user-modify-playback-state` scopes.
- Standard Windows Electron builds do not provide the Widevine CDM required by Spotify Web Playback SDK. Blink now uses Castlabs Electron for Content Security (`45.2.1+wvcus`), installs the Widevine CDM through the Component Updater before opening the window, and enables Spotify playback inside Blink.
- The first launch requires an internet connection for the Widevine CDM installation. Castlabs development binaries are VMP-signed for development; production distribution may require Castlabs EVS/VMP signing and must comply with Spotify Developer Terms.
- Updated Spotify search to use the February 2026 Development Mode maximum of 10 results per request and an explicit RU market. The market is required when the user country is not available in the current `/me` response; the previous request could fail even with the corrected limit.

Important limitations
---------------------
- No Spotify streaming inside Blink is implemented yet; Spotify catalog results open in the official Spotify client. Local audio files play inside Blink.
- A provider OAuth app and secure auth flow are required before real accounts can connect. Spotify developer credentials and a registered redirect URI will be needed. Confirm the available VK and Yandex APIs and their terms before promising playback.
- The local audio library and player support real imported audio files, including playback, pause, seeking, navigation, and volume control.
- The theme switch currently selects an alternate neutral palette, not a complete theme editor.
- Capacitor packages are installed; no Android/iOS project has been generated or built. iOS builds require macOS and Apple tooling.
- Git was not found on PATH in this environment, so no repository or commit checkpoint exists. Git and GitHub setup remain outstanding. Keep this log updated before significant changes until Git is installed.
- Windows installer was built unsigned; Windows may show an unknown-publisher warning.
- Google Fonts are requested remotely; if unavailable, system sans-serif fallbacks are used.
