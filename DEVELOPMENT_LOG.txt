======================

Project
-------

Important limitations
---------------------
- No real Spotify, VK Music, or Yandex Music account sign-in or music stream has been implemented. Provider selection and track playback are UI demonstrations, not connected service features.
- A provider OAuth app and secure auth flow are required before real accounts can connect. Spotify developer credentials and a registered redirect URI will be needed. Confirm the available VK and Yandex APIs and their terms before promising playback.
- The volume control and track navigation update demo UI state; no audio files or actual playback engine are included.
- The theme switch currently selects an alternate neutral palette, not a complete theme editor.
- Capacitor packages are installed; no Android/iOS project has been generated or built. iOS builds require macOS and Apple tooling.
- Git was not found on PATH in this environment, so no repository or commit checkpoint exists. Git and GitHub setup remain outstanding. Keep this log updated before significant changes until Git is installed.
- Windows installer was built unsigned; Windows may show an unknown-publisher warning.
- Google Fonts are requested remotely; if unavailable, system sans-serif fallbacks are used.
