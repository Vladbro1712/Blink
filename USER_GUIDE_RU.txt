# Blink

Blink — проект музыкального проигрывателя для нескольких площадок. Первая версия содержит русский интерфейс для Windows и браузера; структура проекта подготавливается к будущей версии Android.

## Что уже готово

- Главная страница с рекомендациями и поиском треков.
- Раздел «Любимые» с добавлением и удалением избранных.
- Выбор Spotify, VK Музыки или Яндекс Музыки и настройка запоминания выбора.
- Настройки интерфейса, громкость, кнопки плеера и переключение демонстрационных треков.
- Адаптивное оформление в тёплых нейтральных цветах по присланному образцу.
- Локальные обложки, не требующие интернет-подключения.
- Windows-установщик: `release\Blink Setup 0.1.0.exe`.
- Основа Capacitor для будущего Android-приложения.

**Важно:** реальные входы в Spotify, VK и Яндекс Музыку и настоящее воспроизведение пока не реализованы. Плеер демонстрационный. Для подключения площадки понадобятся доступные API, регистрация приложения разработчика и OAuth. Проверьте правила сервисов до начала интеграции. Пароли и секретные ключи не добавляйте в переписку или GitHub.

## Как запустить в браузере

```powershell
cd C:\Code\Blink
npm install
npm run dev
```

## Как запустить приложение Windows в режиме разработки

```powershell
npm run desktop
```

## Как собрать установщик Windows

```powershell
npm run desktop:build
```

Файл установщика появится в папке `release`. Он собран без сертификата подписи, поэтому Windows может показать предупреждение о неизвестном издателе.

## Проверки

Команды `npm run build`, `npm run lint` и `npm run desktop:build` прошли успешно. В среде разработки открыт браузерный предпросмотр на http://localhost:5173/.

## Git и сохранение версий

Git не установлен или не найден в текущей среде. До установки Git журнал работ находится в `DEVELOPMENT_LOG.txt`. После установки откройте PowerShell в папке проекта и создайте контрольную точку:

```powershell
cd C:\Code\Blink
git init
git add .
git commit -m "Начальная версия Blink"
```

Перед следующими важными изменениями создавайте отдельный коммит: добавьте изменённые файлы через `git add .` и сохраните через `git commit -m "Описание изменения"`. Не публикуйте секретные ключи.

## Что делать дальше

1. Установить Git и создать резервную копию проекта на GitHub.
2. Выбрать площадку для первой настоящей интеграции и зарегистрировать приложение разработчика.
3. Проверить возможности и правила API VK Музыки и Яндекс Музыки.
4. Реализовать безопасный вход, поиск каталога и разрешённое потоковое воспроизведение.
5. Создать и проверить Android-проект. Для сборки iOS понадобятся Mac и инструменты Apple.

Технический журнал с ограничениями и результатами проверок: `DEVELOPMENT_LOG.txt`.
